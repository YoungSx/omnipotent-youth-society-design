# 冀西南视觉设计技能 (Inside the Cable Temple Design Skill)

这是用于将万能青年旅店第二张专辑《冀西南林路行》（Inside the Cable Temple）的装帧美学（阮千瑞设计）蒸馏并转译至现代界面的专业设计技能。

---

## 1. 核心审美灵魂与心智模型

万青二专的视觉绝不是通俗的“国潮古风”，也不是喧闹的“黑金摇滚”，更不是仙侠玄幻。它的精神内核是：
**太行山脉的地质崩解、现代工程的开凿重器、与汉魏六朝石刻在工业废墟中的沉郁共鸣。**

作为设计 Agent，在生成任何界面或组件前，必须在心智中确立以下四条物理定律与一条绝对隔离原则：

1. **拓片负像与二维平面律（Negative Rubbing & 2D Planar Physics）**：
   - 黑色不是背景，而是被松烟墨渗透的厚重石质；浅色线条不是“绘制的线条”，而是石面被凿出的凹陷、未着墨处的露白。
   - **拓片是从石壁揭下的平整宣纸，属于纯二维平面**。字迹只有浓淡平墨，绝无三维投影。**严禁使用单向假光源（如 text-shadow: 1px 1px ...）伪造所谓的石刻凹陷或浮雕立体感（Bevel & Emboss）**。
   - 绝不使用发光效果（text-shadow 荧光、发光渐变）。所有质感必须呈现为吸光、干涩、沉稳的纯二维矿物哑光（2D Mineral Matte）。
2. **工业测绘与工程理性（Industrial Survey Mechanics）**：
   - 界面中的细线不仅是石刻阴线，更是工程蓝图与地质剖面基准线。
   - 使用印刷对齐十字准星（`+`）、经纬坐标、标高与技术参数。**这是压制一切泛古风情绪、确立现代冷峻秩序的核心对冲武器**。
3. **经折装时空律（Accordion Register）**：
   - 摒弃千篇一律的卡片瀑布流。界面应具有风琴折页（Sutra Binding）的“定帧展开感”与“行旅节奏”。
   - 极繁与极简的剧烈振荡：繁密风化的微观图腾，必须被大片广阔沉默的留白包裹。
4. **冷峻档案感（Archival Severance）**：
   - 远古兽形残片必须与严苛的现代出版信息（两位数编号、地理坐标、微型衬线英文、精确出处）毫无过渡地并置。字迹古拙，排版秩序必须近乎考古档案。
5. **绝缘隔离原则（No Distress & No Faux 3D on Typography）**：
   - 拓片只属于石刻图腾图像；文字与控件属于现代工业活字印刷。
   - **严禁在文字上添加任何数码斑驳、刮痕、做旧噪点或单向凹陷阴影**。文字必须保持现代铅字的绝对锐利度、最高可读性与纯二维平面感。

## 2. 生产级设计令牌 (Design Tokens)

直接在项目的 CSS / 样式体系中注入以下物理常量：

```css
:root {
  /* 基础墨石层 (Basalt & Ink) */
  --ink-void:      #0e100c; /* 极深墨核：拓片裁切区、深度雕刻背景 */
  --ink-primary:   #171913; /* 矿物深墨：默认墨底，带极微弱太行山冷杉暗绿 */
  --ink-subtle:    #24261e; /* 浅印墨：深色底的微层级分块 */

  /* 纤维纸料层 (Pulp & Mineral) */
  --paper-base:    #d3cbb4; /* 楮皮生纸：默认纸色、墨底主要文字色 */
  --paper-bright:  #e4ddcb; /* 矿物白垩：高对比主文字、强视觉焦点 */
  --paper-section: #dfd8c4; /* 裱纸中层：纸色模式下的承载面板底色 */

  /* 风化与刻痕 (Weathering & Incision) */
  --dust-stone:    #a8a18b; /* 石尘灰：次级说明文字、微型档案参数 */
  --earth-slate:   #847b62; /* 山脊泥土：图注与边缘蚀刻感 */
  --line-carve:    #4c4c3e; /* 刀凿暗线：深色模式分栏线（石刻阴线 / 测绘基准） */
  --line-paper:    #a49e8a; /* 折页阴影：浅色模式分栏线（纸张折痕） */

  /* 伴生印记层 (极度克制，全屏占比 < 2%) */
  --iron-rust:     #9c5847; /* 氧化铁赭石：用于重要状态标记，非鲜艳朱印 */
}
```

## 3. 字体排印公理与层级模数

| 层级 | 字体族族谱 | 典型尺寸 | 字距 (Tracking) | 规则与特殊处理 |
| :--- | :--- | :--- | :--- | :--- |
| **主标题大字** | 开源 `Ma Shan Zheng` / 魏碑 / 六朝造像体 | clamp(56px, 13vw, 166px) | 0.02em ~ 0.05em | 偶数字符微下沉（`translateY(6px)`）模拟摩崖依势题刻；**文字为纯二维哑光平墨，严禁字面做旧与假 3D 凹凸浮雕阴影**。 |
| **正文长文** | 思源宋体 / `"Noto Serif SC"`, serif | 14px – 16px | 0.04em ~ 0.06em | 行高 1.85 ~ 2.0。绝对禁止全篇书法毛笔化，保持宋体的端庄清朗。 |
| **西文题铭** | Georgia / `"Times New Roman"`, serif | clamp(10px, 1.6vw, 20px) | **0.20em ~ 0.25em** | 全大写（UPPERCASE），字号小，字距大幅拉开，传达唱片出处与档案感。 |
| **工程测绘标** | Georgia + 等宽数字 | 10px – 12px | 0.15em | 两位数前导（`01 /`）、经纬度（`LAT. 38°02'N`）与极细十字准星（`+`）。 |

## 4. 四大版式原型选择指南

在构思页面结构时，根据用户的实际业务任务选择以下一种或组合：

### 4.1 符号页原型 (The Monolith Page)
- **适用场景**：专题首页、封面导览、关键叙事锚点。
- **布局规则**：
  - 核心位置安放单一石碑比例拓片（宽高比严格限制为约 1.9 : 1）。
  - 四角设置极细直角定位折标（Corner Marks）。
  - 上下留白不低于图形高度的 60%，杜绝无关装饰，让一个图腾承受全页重量。

### 4.2 经折卷原型 (The Sutra Accordion)
- **适用场景**：多章节长卷漫游、时空叙事、音轨目录。
- **布局规则**：
  - 上方为等分经折导航条（8 段或 6 段，每段标定汉字与西文微标）。
  - 下方横向视口（`overflow-x: auto`）展示连续长卷插图。
  - **核心交互要求**：点击章节平滑驱动（`scrollTo`）长卷移动到对应折位，并伴有折痕指示尺联动；桌面端支持 1:1 跟手鼠标抓取与滚轮横向映射，严禁图文割裂。

### 4.3 金石拓原型 (The Stele Matrix)
- **适用场景**：展览排期、文献列表、多源对比。
- **布局规则**：
  - 借鉴巡演海报布局，以细墨线（`1px solid var(--line-carve)`）划定坚固的非对称石刻槽格。
  - 槽内信息高密度且极规整，大字竖排与小字横排形成金石与工程图纸构架。

### 4.4 档案志原型 (The Archival Index)
- **适用场景**：藏品图录、文献库、素材检视。
- **布局规则**：
  - 采用展签式基座（Matting Frame）：每件展品嵌于低对比微墨衬底中。
  - 检视器（Inspector）提供展开大图、原始出处链接及物理尺度注释。

## 5. 铁律：必须坚决杜绝的十大过度设计反模式

在审查或生成代码时，任何以下特征均属于严重审美降级，必须立即清除：

1. ❌ **严禁文字数码做旧与假 3D 浮雕阴影（No Distressing & No Faux 3D Bevel）**：严禁在文字上应用噪点遮罩、斑驳裂纹或破损滤镜，**严禁添加任何带有方向性光源的凹陷/浮雕阴影（如 text-shadow: 1px 1px ...）**。拓片是一张平面的纸，文字必须保持现代活字印刷的极致边缘锐度、最高阅读对比与纯二维哑光墨色。
2. ❌ **严禁撕纸毛边与烧焦孔洞**：容器边缘必须是坚决利落的工业直线（0~2px 圆角），禁止低级手工折纸做旧。
3. ❌ **严禁全屏动态飘落微粒**：严禁漂浮灰尘、火星或雪花 Canvas 动效。太行山是沉寂凝固的，文字应当如刀刻般静止。
4. ❌ **严禁多重裂纹法线贴图**：背景纸浆噪点透明度严格控制在 `<= 0.04`，禁止叠加纸张褶皱法线或暗角。
5. ❌ **严禁艳俗朱红仿古印章**：严禁在角落放置歪斜的、红色小印章（类似文创书签套路）。二专是冷酷现代的装帧，不需要庸俗仿古点缀。
6. ❌ **严禁黑金与金属渐变**：严禁高光金属黄（#FFD700）、金粉闪烁或彩色渐变。金是风化矿土。
7. ❌ **严禁圆角卡片流与弥散彩色阴影**：`border-radius` 最大不超过 2px（推荐 0px）。严禁现代 SaaS 风格的大圆角和弥散阴影。
8. ❌ **严禁长篇正文书法化**：阅读区必须保持宋体，书法只允许出现在极少数大字标题中。
9. ❌ **严禁轻浮弹跳动效**：严禁 bounce、浮动动画或跟随鼠标晃动。转场时间控制在 180~300ms（推荐 `cubic-bezier(0.16, 1, 0.3, 1)`），沉着如翻开厚纸。
10. ❌ **严禁虚构文物考据与假声波控件**：对未确定出处的古代图像，一律标记为“古代兽形/图像”；非真实音频界面禁止安放假声波。

## 6. Agent 执行工作流 (Step-by-step Workflow)

当用户要求设计一个符合万青二专风格的页面或组件时，严格按此步骤推进：

1. **第 1 步：剥离与选型**
   - 确定用户目标（文献档案？音乐漫游？还是单幅专题？）。
   - 从第 4 节中挑选核心原型（符号页 / 经折卷 / 金石拓 / 档案志），画出版面骨架。
2. **第 2 步：注入色彩与质感层**
   - 引入第 2 节的 CSS 变量。
   - 在主容器使用内联 SVG fractalNoise 生成微弱的矿物吸光层（opacity: 0.038）。
3. **第 3 步：建立排印张力与工程对冲**
   - 标题大字采用 `Ma Shan Zheng` 或魏碑，偶数字符做 6px 错落微移，西文全大写拉开字距至 0.22em。
   - 加入测绘十字准星（`+`）与两位数编号，对冲古风感伤。
   - **文字绝对保持边缘锋利，禁止做旧噪点**。
4. **第 4 步：拓片与经折交互实现**
   - 拓片图像严格保留纯黑石底与浅矿线刻，杜绝发白发灰。
   - 多章节切换时，联动滚动区域（`scrollTo`），提供物理经折展开感。
5. **第 5 步：严苛反模式自检**
   - 运行第 5 节的 10 项铁律逐项核对，确保 100% 洁净后方可交付。
