## 1. 审美本体论：从山川、矿石与重器中蒸馏

《冀西南林路行》（Inside the Cable Temple）的视觉语言不是通俗意义上的“国潮古风”，不是泛化的“黑金摇滚”，更不是仙侠神话。它的内核是**太行山脉的地质沉沦、工业重器的剧烈切割、以及汉魏石刻在现代废墟中的回响**。

设计者（阮千瑞）通过双专色经折装、碑拓线刻负像、粗砺纸料与冷峻现代出版信息的冲突并置，构建了一套独特的东方现代主义设计范式。将此风格转译至数字界面时，必须严格遵循以下四层本体力学与一层克制隔离：

### 1.1 拓片负像力学（Negative Rubbing Mechanics）
- **基底为石，空处为线**：画面中的“黑”不是黑暗背景，而是被墨层层浸透的石板原体；“浅线”不是画上去的线条，而是石壁受刀斧凿刻后下陷、拓包无法触及而露出的岩石原本肌理。
- **拒斥数码浮光**：任何发光（text-shadow 荧光、高光渐变、透明度杂质叠加）都是对金石质感的破坏。图像必须呈现为渗入纸浆纤维与干燥矿粉的哑光质感（Matte/Mineral Dryness）。

### 1.2 工业测绘与地质剖面力学（Industrial Survey & Section Mechanics）
- **工程缆寺的冷酷理性**：万青二专不仅是古代山林，更是现代工程开凿的现场（Cable Temple / 掘进 / 炸药 / 标高 / 经纬测绘）。
- **细线的双重身份**：界面中的 1px 细线不仅是石刻阴线，更是工程蓝图与地质断层图的基准线。
- **测量标记的对冲作用**：引入印刷十字定位准星（Registration Cross `+`）、勘探孔编号（如 `DH-04`）、经纬度坐标与绝对标高。**这种近乎冷酷的现代工程档案秩序，是压制一切廉价“古风感伤”的核心对冲武器**。

### 1.3 经折装的时空折叠律（Accordion Register）
- **折页即停顿，展开即行旅**：物理唱片为双面风琴折（长卷横向展开）。在数字界面中，构图应摒弃无限平铺的卡片瀑布流，转为“经折展卷”的章节定帧感。
- **疏密对撞（Density Oscillation）**：极度繁复、充满风化与残损的微观图腾（如墨麒麟鳞甲、采石工地），必须被极其广袤、沉穆、空无一物的静默留白所包围。信息密度在 0% 与 90% 之间剧烈震荡，严禁均质化填满。

### 1.4 汉魏残片与当代档案的暴力并置（Archaic & Archival Juxtaposition）
- **时间层叠**：远古兽形、摩崖造像题记的残缺骨架，与现代铅字、出版编号、地理坐标、技术参数毫无过渡地贴合在同一平面上。
- **严谨的文献冷感**：字迹可以古拙，但排版逻辑必须具备近乎考古档案般的绝对秩序。

### 1.5 绝缘原则：拒斥数码拟物病与过度做旧（Refusal of Digital Distress Kitsch）
必须在物理架构上将版面严格区隔为两个互不污染的图层：
1. **图腾层（The Rubbing Plane）**：仅用于石刻拓片图像自身。容许其自带的石壁残损与拓印斑驳。
2. **排印层（The Typographic Plane）**：涵盖所有汉字正文、西文题铭、线框、按钮与数据标签。**此层属于现代工业印刷的活字/铅字**，笔画边缘必须绝对锐利、坚中正中，严禁施加任何做旧磨损滤镜！

## 3. 色彩系统：矿物与纸浆色谱 (Mineral & Pulp Palette)

所有色值模拟未漂白厚棉纸、矿石粉末、氧化铁与松烟墨的物理干涉效果。**严禁使用高饱和色彩、金属反射渐变或纯白（#FFFFFF）/纯黑（#000000）。**

```css
:root {
  /* 基础质感层：石板基底与墨层 */
  --ink-void:       #0e100c; /* 极深玄武墨：拓片核心沉墨区，用于局部裁切与重压区 */
  --ink-primary:    #171913; /* 矿物深墨：默认大面积墨底，略带冷杉土绿倾向 */
  --ink-subtle:     #24261e; /* 浅印墨：深色底上的微弱分块与次级底色 */

  /* 纤维质感层：未漂白纸料与风化矿粉 */
  --paper-base:     #d3cbb4; /* 楮皮生纸：默认纸色、主标题文字色、反白阅读层 */
  --paper-bright:   #e4ddcb; /* 矿物白垩：高对比主文字、强视觉焦点，非漂白荧光白 */
  --paper-section:  #dfd8c4; /* 裱纸中层：纸色模式下的承载面板底色 */

  /* 剥蚀与风化层：太行石屑与泥沙 */
  --dust-stone:     #a8a18b; /* 石尘灰：次级说明文字、辅助档案编码、微弱分隔 */
  --earth-slate:    #847b62; /* 山脊泥土：风化色样，图注与边缘蚀刻感 */
  --line-carve:     #4c4c3e; /* 刀凿暗线：深色模式分栏线，模拟石刻阴线与工程测绘基准 */
  --line-paper:     #a49e8a; /* 折页阴影：浅色模式分栏线，模拟纸张折痕 */

  /* 伴生印记层：氧化铁与矿物印泥（极度克制，占版面 < 2%） */
  --iron-rust:      #9c5847; /* 铁锈赭石：仅用于重要状态警示或微小装订标记，非艳俗印章红 */
}
```

### 3.1 对比度与双模式转译规则
1. **墨色模式（Ink Mode - 默认）**：
   - 背景采用 `--ink-primary`（#171913），辅以微弱内联 SVG 矿物噪点（opacity: 0.035~0.045）。
   - 正文采用 `--paper-base`（#D3CBB4），标题采用 `--paper-bright`（#E4DDCB），对比度满足 WCAG AA（> 7:1）。
2. **纸色模式（Paper Mode）**：
   - 背景切换为 `--paper-base`（#D3CBB4），正文切换为 `--ink-primary`（#171913）。
   - 拓片图像（.rubbing）在纸色模式下不得反相为诡异的白色怪物，而必须以**“宣纸托裱原石精拓”**的册页形式呈现：保留深墨框底与内陷微阴影，如同一张真实嵌入浅色册页中的黑石拓片。

## 4. 字体排印：金石骨力与工程测量规制

### 4.1 中文展示大字（Hero Typography）
- **骨力与残损**：优先选用带有六朝魏碑、造像题记、金石残刻气韵的书体。网络开源实现采用 `Ma Shan Zheng`（马善政）时，必须通过 CSS 进行“金石化校准”：
  - **行气微落差（Cadence Shift）**：标题字排布严禁机械居中或两端顶格拉伸。采用偶数字符下沉微移（如 `span:nth-child(2n) { transform: translateY(6px); }`），打破现代活字排版的机械僵直，还原石壁摩崖题刻随势依石的书写呼吸。
  - **严禁字面做旧**：严禁使用 `background-clip: text` 或 SVG 噪点去腐蚀汉字笔画。字体必须保留工整清晰的黑色/纸色墨迹。

### 4.2 正文与目录排印（Text & Indexing）
- **宋体正文**：连续中文阅读必须使用纯粹、工整、中正的宋体/思源宋体（`"Noto Serif SC", "Songti SC", SimSun, serif`）。绝对禁止将大段长文设定为行草或毛笔书法。
- **字号与行气尺度**：
  - 核心正文：14–16px，行高 1.85–2.0，字距 0.04–0.08em。
  - 档案微字：10–12px，行高 1.6，专用于编号、版权、图注与出处。
  - 展示字 vs 微型字比例拉大至 **8:1 到 14:1**（如标题 120px vs 图注 10px），形成强烈的尺度对撞。

### 4.3 西文、编号与工程图例（Latin, Numerals & Survey Marks）
- **冷峻衬线**：西文必须使用具历史感的传统衬线体（Georgia / Garamond），字号小、字距大幅拉开（`letter-spacing: 0.18em ~ 0.25em`），全大写（Uppercase）承担专辑副题、技术参数与出处标注。
- **双位十进制编号**：所有章节、图像、规范条款均以两位数字前导（`01 /`、`02 /`），杜绝口语化编号。
- **工业测绘图例**：
  - 坐标格式：`LAT. 38°02'N / LON. 114°29'E`
  - 标高图示：`ELEV. +1124M`
  - 准星标记：在主图或分栏交叉点点缀极细十字准星（`+`，font-size: 10px, opacity: 0.5）。

## 5. 构图模数、断点拓扑与经折布局法

二专视觉禁止使用“圆角阴影通用卡片”或“均匀九宫格”。版面由四种核心原型推导：

### 5.1 原型一：符号页（The Monolith Page）
- **构图**：画面正中为一个绝对压迫感的单一图腾（如墨麒麟拓片），宽高比严格锁定在石碑矩形（约 1.8 : 1 到 1.95 : 1）。
- **留白**：符号周围必须留出不低于符号自身高度 60% 的纯净空底。
- **角标定位**：四角点缀极细的直角定位标（Corner Mark），象征拓印定位线或版画刻版边界。

### 5.2 原型二：经折卷（The Sutra Accordion）
- **联动漫游**：经折装必须体现八折叙事（早、泥河、平等云雾、采石、山雀、绕越、河北墨麒麟、郊眠寺）。
- **视口锚定**：曲目点击平滑驱动长卷滚动至对应的经折区间，下方附带折痕刻度尺（Progress/Fold Bar），杜绝长卷与章节文字脱节。

### 5.3 原型三：金石拓（The Stele Matrix）
- **多层石板分栏**：借鉴 2023/2024 巡演海报，版面由粗细不均的墨线切分为上中下、左中右多级信息槽（Slot），文字严密嵌于槽内，形成摩崖造像龛与工程立面板的错落秩序。

### 5.4 原型四：档案志（The Archival Index）
- **拓片底托（Matting Frame）**：图录陈列应如同博物馆库房展签。每张图像置于浅一阶的微墨托盘中，四边细线约束，悬停时产生拓片揭起的微妙透明度变化。

### 5.5 经折装的断点拓扑学（Responsive Fold Topology）
- **宽屏桌面端（Desktop > 1024px）**：经折装水平展开为宽长卷（物理连续性），通过横向拖拽、滚轮平移与折位刻度尺浏览。
- **移动竖屏端（Mobile < 768px）**：不可强行缩成一条无法辨识的极扁微缩缝隙，而应折叠为“垂直经折风琴页”——上一章节收起、当前章节展开、折位处以虚线折痕标出折入与折出，保持经折装在不同维度上的物理自洽。

## 6. 时间与重力阻尼（Chronomechanics）

界面的动态表现必须符合“岩石位移”与“厚磅棉纸翻折”的物理直觉：

1. **重物惯性缓动**：
   - 动画时间严控在 180ms ~ 300ms 之间。
   - 推荐缓动曲线：`cubic-bezier(0.16, 1, 0.3, 1)`（启动冲力强、长距离沉稳制动），杜绝任何果冻回弹（bounce / overshoot）。
2. **物理断脆切档**：
   - 主题切换（墨色 ⟷ 纸色）必须瞬时或极短过渡（`instant` 或 `<= 120ms`），模拟暗房曝光开关或物理专色印版替换，严禁现代 UI 绵软无力的 500ms 渐变。

## 7. 过度设计绝对黑名单（Over-Design Blacklist）

在任何生成或实现中，以下过度修辞行为被视为严重美学污染，严厉禁止：

1. ❌ **严禁文字数码做旧（Distressed Typography）**：严禁在文字上应用噪点遮罩、斑驳裂纹、笔画缺损滤镜。文字必须保持现代活字印刷的极致边缘锐度。
2. ❌ **严禁撕纸毛边与烧焦孔洞（Torn/Burned Edges）**：容器与画幅边缘必须是坚决利落的工业直线（border-radius: 0~2px）。禁止低级手工撕纸感。
3. ❌ **严禁全屏动态飘落微粒（Drifting Dust/Spark Particles）**：禁止引入漂浮灰尘、火星或雪花 Canvas 动效。太行山是沉寂凝固的，文字应当如刀刻般静止。
4. ❌ **严禁多重裂纹贴图叠加（Texture Soup）**：背景纸浆噪点透明度严格控制在 `<= 0.04`，禁止叠加纸张褶皱法线、石壁龟裂大图或暗角暗影。
5. ❌ **严禁艳俗朱红仿古印章（Kitsch Red Seals）**：严禁在页面角落随意放置倾斜、圆角、低质的仿古朱红小印章。这属于廉价旅游文创套路，彻底摧毁二专冷峻沉毅的气场。
6. ❌ **严禁黑金与流光金属渐变（Metallic Gradients）**：严禁使用亮黄、流光金色（#FFD700 等）及金属渐变。二专的“金”是矿石中的暗哑云母与纸浆尘埃。
7. ❌ **严禁现代 SaaS 风格大圆角与弥散彩色阴影**：严禁使用 8px+ 圆角或彩色发光阴影。
8. ❌ **严禁长篇正文书法化（Calligraphic Long-text）**：长段正文必须使用清晰的宋体，严禁全篇毛笔字。
9. ❌ **严禁虚构考古定论（Fictional Archeology）**：未经确证的历史出处必须声明“出处尚未确认”，禁止杜撰朝代定论。
10. ❌ **严禁虚假播放器与假声波（Fake Audio Controls）**：非真实音频页面不得放置不可点击的伪播放进度条、旋转唱片或假声波。

## 8. 终极验收清单 (Audit Checklist)

交付给用户或 downstream agent 前，必须逐项核对：

- [ ] **骨架纯粹性**：去掉所有歌词与专辑文字后，页面是否依然呈现出强烈的金石、经折、档案文献感？
- [ ] **文字锐利度**：所有文本是否维持纯正高对比印刷边缘，没有任何劣质斑驳做旧？
- [ ] **冷峻对冲度**：版面中是否有细线、十字准星或两位数编号对冲古拙感，是否彻底杜绝了廉价“古风感伤”？
- [ ] **材质沉着感**：背景是否消除了纯平面数码感？墨色是否有厚度？纸色是否有呼吸？
- [ ] **拓片层次**：核心图腾是否深沉入石？有无发白、发灰、失真的图层叠加穿帮？
- [ ] **双模自洽**：纸色模式下，面板与拓片是否依然具备清晰的层级与阅读对比？
- [ ] **经折联动**：章节切换与长卷视口是否具备物理叙事呼应？
- [ ] **响应性与无损**：在 360px 窄屏与 1440px 宽屏下均无横向溢出，所有功能与链接真实可用。
